This repository contains the data for the paper "_Religion_ as a concept in Syriac" by Briana Grenert (Duke University) and Slavomír Čéplö (BBAW / IOS Slovak Academy of Sciences).

The data consists of the following:
- `Code`: The code used for the training of the word2vec models and for the quantitative analysis.
- `Models`: Two models - word2vec model (WORDS) and lemma2vec model (LEMMATA) - in keyed vector format.
- `Section2.2-Simtho_texts.tsv`: the list of texts covered by *Simtho* and thus the data sets used to train the models.
- `Section3.1-Quantitative data`: data used to produce the figures in section 3.1.
- `Section3.2-Qualitative data`: data used to produce the figures in section 3.2.
